# QA Automation Architecture

**Goal:** Fully automated test generation - no manual wiki updates needed

---

## 🎯 System Design

```
EXCEL FILE (Source of Truth)
    ↓ (qa/LD-Expert-QA.xlsx)
    ├─ Developer adds test case rows
    ├─ No wiki updates needed
    └─ Single source of truth

/qa-generate-tests SKILL (Automated)
    ↓ (reads Excel, generates code)
    ├─ Parses test cases
    ├─ Generates PHP test files
    └─ No manual code writing

PHP TEST FILES (Auto-generated)
    ↓ (tests/BrowserQA/)
    ├─ Admin/ (auto-generated)
    ├─ Therapist/ (auto-generated)
    └─ E2E/ (auto-generated)

php artisan dusk (Execution)
    ↓ (runs tests in browser)
    ├─ Executes all steps
    ├─ Records results
    └─ No manual testing

qa/reports/ (Results)
    ↓ (auto-generated reports)
    ├─ HTML report (dusk-[timestamp].html)
    ├─ JSON data
    └─ Test log

DONE ✅
```

## 📊 Who Does What?

### **Developer (When Adding New Feature)**
```
Task: Add a new test case

What they do:
1. Open qa/LD-Expert-QA.xlsx
2. Add one row with:
   ├─ TC-ID: TC-A013
   ├─ Title: Feature name
   ├─ Module: Module
   ├─ Steps: What to do
   ├─ Expected Result: What happens
   ├─ Role: Admin/Therapist/E2E
   └─ Priority: P1/P2
3. Save file
4. Done

What they DON'T do:
├─ Update wiki.md ✓ (no need)
├─ Update README.md ✓ (no need)
├─ Update DOCS ✓ (no need)
├─ Write PHP code ✓ (auto-generated)
└─ Write test code ✓ (auto-generated)
```

### **System (Automated)**
```
Task: Generate and run tests

What the system does:
1. /qa-generate-tests reads Excel
2. Generates PHP test files
3. Stores in tests/BrowserQA/
4. php artisan dusk runs tests
5. Generates report in qa/reports/
6. Done

What it requires:
└─ Excel file with test cases (human provides)
```

## 🛡️ Quality Assurance

### **How Do We Keep Excel File Valid?**

```
Excel file validation:
├─ Required columns: TC-ID, Title, Module, Steps, Expected Result, Role, Priority
├─ TC-ID must be unique
├─ Role must be: Admin, Therapist, or E2E
├─ Priority must be: P1 or P2
└─ /qa-generate-tests validates before generating

If invalid:
├─ /qa-generate-tests shows error
├─ Developer fixes Excel
├─ Re-run /qa-generate-tests
```

### **How Do We Keep Tests Fresh?**

```
When Excel changes:
1. Developer updates qa/LD-Expert-QA.xlsx
2. Runs /qa-generate-tests
3. Tests are regenerated (old ones deleted, new ones created)
4. php artisan dusk runs
5. System always has latest tests

Automatic refresh ✅
```
